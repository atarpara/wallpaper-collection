# Wallpaper Collection

A personal collection of high-resolution (4K to 8K) desktop wallpapers.

## What's inside

- Anime: Demon Slayer, Jujutsu Kaisen, Naruto, One Piece, Attack on Titan, My Hero Academia, Haikyu!!, Solo Leveling, Dandadan, and more
- Superheroes: Spider-Man, Batman, Deadpool, Black Panther, Daredevil, Venom
- Cars: Ford GT, Ford Mustang GT, Lamborghini
- Spiritual art: Lord Krishna, Lord Shiva, Adiyogi, Bajrangbali
- Minimal and AMOLED wallpapers

## How to use

Download any image and set it as your desktop or phone wallpaper. To get everything at once:

```sh
git clone https://github.com/atarpara/wallpaper-collection.git
```
